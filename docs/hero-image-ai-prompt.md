## Generation Settings

- **Aspect Ratio**: 16:9 (landscape)
- **Resolution**: 4096x2160 minimum
- **Style**: Vector/Flat or 3D Isometric
- **Background**: Transparent (PNG) or pure white
- **Color Palette**: Primary Dark Red (#8B1538), White, Soft Gray (#F5F5F5)

## Post-Processing Requirements

After generation:
1. Remove any text/watermarks
2. Ensure transparent background
3. Optimize to WebP under 500KB
4. Generate responsive variants:
   - Desktop: 1920px width
   - Tablet: 768px width
   - Mobile: 480px width
   - Thumbnail: 200px width
