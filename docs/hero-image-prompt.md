# AI Image Generation Prompt — 4CoreFinSupport Hero Image

Use this prompt with high-quality image generation models (DALL-E 3, Midjourney v6, Flux Pro, Ideogram 2.0).

---

## Prompt

A premium, modern enterprise illustration for a financial operations and compliance platform. The scene depicts a sleek, dark-red and white themed digital command center. In the center, a large transparent holographic dashboard floats above a polished dark desk surface, displaying interconnected data visualizations: a financial KPI line chart in dark red, a compliance checklist with checkmarks, a workflow diagram with connected nodes showing approval processes, and a real-time notification feed. Surrounding the dashboard, subtle floating UI elements — document icons, security shields, calendar icons, user avatars in a circle, and a cloud infrastructure symbol — orbit gently, representing the integrated modules of the platform. The background is a very light gray gradient with soft geometric shapes and faint grid lines, conveying technology and precision. The overall style is vector-inspired, clean, minimal, and premium — similar in quality and aesthetic to Microsoft 365, Notion, Stripe, or Atlassian illustrations. No text, no watermarks, no cartoon elements. The color palette is strictly dark red (#8B0000), white, and soft gray (#E5E7EB) with subtle shadows and soft lighting. Landscape orientation, 16:9 aspect ratio, 4K resolution, ultra high quality, transparent background preferred.

---

## Negative Prompt (for models that support it)

No cartoons, no clipart, no busy backgrounds, no unnecessary decorative elements, no text, no watermarks, no low quality, no blurry, no oversaturated colors, no bright neon colors, no people faces, no photographs, no realistic style.

---

## Settings

- **Aspect Ratio:** 16:9
- **Resolution:** 4K (3840x2160)
- **Style:** Vector illustration / 3D render
- **Color Palette:** Dark Red (#8B0000), White, Soft Gray (#E5E7EB)
- **Background:** Transparent or very light gray (#F8F9FA)
- **Quality:** Ultra high, premium, enterprise-grade

---

## Model-Specific Tips

- **DALL-E 3:** Use the prompt as-is. Request "vector illustration style" explicitly.
- **Midjourney v6:** Append `--ar 16:9 --style raw --stylize 200` at the end.
- **Flux Pro:** Use the prompt directly; set guidance scale to 7.5.
- **Ideogram 2.0:** Use the prompt as-is; select "Illustration" style.
